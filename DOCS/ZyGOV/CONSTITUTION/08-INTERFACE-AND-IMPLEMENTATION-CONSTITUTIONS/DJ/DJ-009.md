# DJ-009 — Developer Journey 009
 
## Publish Marketplace Extensions
 
**Document ID:** DJ-009 **Layer:** Layer 4 — Developer Platform **Status:** Canonical Developer Journey **Depends On:** DJ-001 through DJ-008, DEV-ARCH-001, MARKETPLACE-SPEC-001, SDK-SPEC-001, PLUGIN-SPEC-001, SEC, POL
  
# 1. Purpose
 
This journey teaches developers how to build, certify, publish, maintain, and monetize extensions for the Zyppi Marketplace.
 
By this stage, developers have learned how to consume Zyppi capabilities. This journey shifts perspective from **consumer** to **ecosystem contributor**, enabling organizations and independent developers to extend the platform without altering its constitutional behavior.

# 7. Marketplace Philosophy
 
The Marketplace extends Zyppi's capabilities without fragmenting the platform.
 
Every published extension must:
 
 
- respect constitutional rules
 
- preserve Runtime guarantees
 
- maintain deterministic behavior
 
- pass certification
 
- remain compatible with supported platform versions

# 10. Certification
 
Marketplace extensions undergo certification before publication.
 
Certification validates:
 
 
- Runtime compatibility
 
- SDK compatibility
 
- Security requirements
 
- Constitutional compliance
 
- Performance requirements
 
- Dependency integrity
 
- Quality standards
 

 
Certification does not validate business value.
 
It validates platform compatibility.
