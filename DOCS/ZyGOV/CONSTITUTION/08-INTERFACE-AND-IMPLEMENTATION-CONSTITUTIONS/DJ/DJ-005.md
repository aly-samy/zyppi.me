# DJ-005 — Developer Journey 005
 
## Integrate an ERP System
 
**Document ID:** DJ-005 **Layer:** Layer 4 — Developer Platform **Status:** Canonical Developer Journey **Depends On:** DJ-001, DJ-002, DJ-003, DJ-004, DEV-ARCH-001, ZRM, ARM, PRJ, POL, SEC, RI
  
# 1. Purpose
 
This journey teaches enterprise developers how to integrate an existing ERP system with Zyppi.
 
Unlike previous journeys, which focus on individual applications, this journey addresses enterprise system integration, where Zyppi complements—not replaces—the organization's existing business systems.
 
The objective is to synchronize trusted business events between the ERP and the Zyppi Runtime while preserving each system's responsibility.
  
# 2. Business Problem
 
Organizations already operate complex ERP environments.
 
Examples include:
 
 
- SAP
 
- Oracle ERP
 
- Microsoft Dynamics 365
 
- Odoo
 
- Infor
 
- Epicor
 
- Sage
 
- Custom ERP platforms
 

 
Replacing these systems is unrealistic.
 
Instead, Zyppi augments them by providing trusted identity, provenance, attestation, digital product passports, ownership, and governed execution.

# 7. Integration Philosophy
 
The ERP remains the **System of Record** for operational business processes.
 
Zyppi becomes the **System of Trust** for:
 
 
- identity
 
- provenance
 
- product lifecycle
 
- governance
 
- attestation
 
- trusted execution
 

 
The two systems collaborate rather than compete.
