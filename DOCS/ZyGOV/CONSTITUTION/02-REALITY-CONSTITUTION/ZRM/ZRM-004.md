# Part I — Event Mathematics

**Status: ✅ Ratified** (mined from legacy corpus; final Registry Freeze, RTC-ZRM-003B-R3)

## 3. Event Mathematics

### **EV-T01 — Event Immutability** 
*(ratified; formerly TH-E001)*

Once a constitutional Event exists, it SHALL never be modified: `∀ e ∈ Event, ∀ t₁ < t₂ : e(t₁) = e(t₂)`. Corrections occur only through new Events, never through mutation of an existing one.

### **EV-T02 — Event Atomicity** 
*(ratified; formerly TH-E002)*

Every constitutional Event is an indivisible unit of constitutional change — no Event may be partially applied or partially exist.

### **EV-T03 — Event Occurrence Uniqueness** 
*(ratified; formerly TH-E003)*

Every constitutional Event represents exactly one unique constitutional occurrence: no two distinct Events represent the same occurrence, and no single Event represents more than one.

### **EV-T04 — Event Logical Ordering** 
*(ratified; formerly TH-E004)*

Constitutional Events may be ordered by logical precedence independent of chronological time.

> *Cross-reference, not yet reconciled:* this is close to ZRM-003B TM-T01 (Logical Time Ordering), which orders Events by constitutional time rather than by Event-to-Event precedence directly. Whether these are the same ordering relation stated twice, or genuinely distinct relations (one about Time's structure, one about Event dependency), is an open reconciliation question for S6-003 — not resolved in this draft.

### **EV-T05 — Event Causality** 
*(ratified; formerly TH-E005)*

A causal relationship between Events represents dependency, not temporal proximity: `causes(e₁, e₂)` does not require `e₁` and `e₂` to be close in logical time, only that `e₂`'s occurrence depends on `e₁`'s.

> *Flag, not resolved here:* Temporal Mathematics (ZRM-003B §8) deferred "Causal Consistency" as unproven during its own purification, while this theorem was independently ratified in the Event family. Before both stand in the final corpus, confirm they're not the same claim reaching two different verdicts.

### **EV-T06 — Event Composition** 
*(ratified; formerly TH-E006)*

Events may compose into higher-order structures while preserving the Identity, Atomicity (EV-T02), and Immutability (EV-T01) of every constituent Event.

### **EV-T07 — Event Idempotence** 
*(ratified; formerly TH-E012)*

Repeated application of the same immutable Event is mathematically equivalent to a single application: `e ∘ e = e`.

### **EV-T08 — Event Liveness** 
*(ratified; formerly TH-E013)*

Every constitutionally valid Event eventually becomes part of constitutional Event history unless constitutionally rejected — no valid Event may remain permanently in limbo.

### **EV-T09 — Event Finality** 
*(ratified; formerly TH-E014)*

Once an Event is recorded and not rejected, its status is final and is never revisited by later Events — distinct from EV-T01 (which governs the Event's content); this governs the Event's standing.
