# Part I — Foundations

## 1. Purpose

RI-001 defines the internal architecture of the ZRM Constitutional Compiler. It specifies the module decomposition, canonical data model, ACV construction algorithm, execution state machine, error namespace, and compliance requirements that every certified implementation must satisfy.

RI-000 governs constitutional stage boundaries and artifact interfaces. RI-001 governs the internal structure that produces those artifacts. An implementation is free to optimize internals provided every constitutional artifact produced is byte-identical to the reference.

## 2. Scope

RI-001 governs the Constitutional Compiler (RI-001 implementation). It does not govern the Population Executor (RI-004B), Verification Framework (RI-003), or Certification Engine (RI-005E), which have separate specifications.

## 3. Constitutional Authority Chain

```
WS-01 through WS-05E (Constitution)
        │
        ▼
RI-000 Execution Contract v1.0
        │
        ▼
RI-001 Constitutional Compiler Architecture v1.0  ← THIS DOCUMENT
        │
        ▼
Implementation (Go / Rust / Python / any language)
```

Lower levels SHALL NOT redefine or weaken guarantees established by higher levels. RI-001 may constrain implementations but may not contradict RI-000 or the Constitution.

## 4. Core Execution Equation

```
PopulationPlan = Compiler(ConstitutionManifest, ActiveConstitutionalView)
```

The compiler is a pure mathematical function. It has no observable side effects. Given identical inputs, it always produces identical outputs regardless of language, OS, hardware, or timing.

## 5. Foundational Rules

**FR-001 — Constitutional Stage Separation**
RI-000 defines five Constitutional Stages identified by immutable artifact boundaries. RI-001 defines modules within those stages. Modules are implementation units — they have no constitutional artifact boundary. Multiple modules collaborate to produce a single stage output artifact.

**FR-002 — Verification Independence**
RI-003 (Verification Framework) SHALL NOT consume intermediate artifacts produced by RI-001. It SHALL independently reconstruct constitutional truth from sealed Phase A artifacts. Consuming RI-001 intermediate artifacts constitutes the Self-Trust Exploit (error 0x00FC).

**FR-003 — Stage Receipt Requirement**
Every stage SHALL emit a Stage Receipt before the next stage may begin. The Artifact Manifest (Stage 5) is the sole consumer of all stage receipts. No receipt may be reconstructed from memory; it must be read from disk.

**FR-004 — Payload Envelope Pattern**
Every constitutional artifact on disk uses a two-key root envelope `{payload, integrity}`. The integrity hash covers exclusively the RFC 8785 canonical serialization of the payload object. The envelope wrapper is never hashed.

**FR-005 — Clock Prohibition**
Runtime system clocks are constitutionally prohibited. All temporal identity derives from `Manifest.sealed_at_unix_ms`, which is established at Phase A constitutional closure and propagated unchanged through every stage.

# Part IV — ACV Construction Algorithm

## 17. Reference Pseudocode

This algorithm is the constitutional reference. Every implementation must produce a `acv.json` with a payload integrity hash identical to the reference for identical inputs.

```
FUNCTION BuildACV(manifest_path: string) → ACVResult:

  # Stage 1: Verify Manifest
  manifest_raw  ← LOAD_FILE(manifest_path)         // M-101
  manifest      ← PARSE_JSON(manifest_raw)

  manifest_canonical ← RFC8785_CANONICALIZE(manifest_raw)
  manifest_hash      ← SHA256(manifest_canonical)

  IF manifest_hash ≠ manifest.integrity.value THEN
    HALT(0x0003, "Manifest root hash mismatch")     // M-102
  END IF

  corpus ← EMPTY_MAP
  FOR doc IN manifest.documents DO                  // M-103
    doc_raw       ← LOAD_FILE(doc.id)
    doc_canonical ← RFC8785_CANONICALIZE(doc_raw)
    doc_hash      ← SHA256(doc_canonical)
    IF doc_hash ≠ doc.integrity.value THEN
      HALT(0x0005, "Document hash mismatch: " + doc.id)
    END IF
    corpus[doc.id] ← PARSE_DOCUMENT(doc_raw)
  END FOR

  RUN_ANNOTATION_LINTING(corpus)                    // M-104
  sr001 ← LOAD_AND_VALIDATE_SR001(corpus)          // M-105
  sia_result ← RUN_SIA001(corpus, sr001)           // M-106
  IF sia_result.status ≠ "PASS" THEN
    HALT(0x0014, "SIA-001 failure: " + sia_result.failed_category)
  END IF

  EMIT_STAGE_RECEIPT(1, "verified.json")            // M-109

  # Stage 2: Build ACV
  active_corpus ← DEEP_COPY(corpus)

  # Apply supersessions in strict sequence order    // M-202
  applied ← EMPTY_SET
  FOR entry IN SORT_BY_SEQUENCE(sr001.entries) DO
    FOR dep IN entry.depends_on DO
      IF dep NOT IN applied THEN
        HALT(0x0021, "Dependency not applied: " + dep)
      END IF
    END FOR
    target_clause ← FIND_CLAUSE(active_corpus,
                      entry.supersedes.document,
                      entry.supersedes.section,
                      entry.supersedes.clause)
    IF target_clause IS NULL THEN
      HALT(0x0022, "Superseded clause not found: " + entry.supersedes)
    END IF
    target_clause.status ← "SUPERSEDED"
    target_clause.superseded_by ← entry.id
    source_clause ← FIND_CLAUSE(active_corpus,
                      entry.superseded_by.document,
                      entry.superseded_by.section,
                      entry.superseded_by.clause)
    source_clause.status ← "ACTIVE"
    applied.ADD(entry.id)
  END FOR

  FOR clause IN ALL_CLAUSES(active_corpus) DO       // M-203
    IF clause.status = "DEPRECATED" THEN
      clause.excluded ← true
    END IF
  END FOR

  graph ← EMPTY_GRAPH                               // M-204
  FOR clause IN ACTIVE_NON_EXCLUDED_CLAUSES(active_corpus) DO
    FOR obj IN EXTRACT_CONSTITUTIONAL_OBJECTS(clause) DO
      obj.source_clause ← MAKE_CLAUSE_REF(clause)
      graph.ADD_NODE(obj)
    END FOR
  END FOR
  FOR node IN graph.nodes DO
    FOR ref IN node.relationships DO
      IF graph.FIND_NODE(ref.target_id) IS NULL THEN
        HALT(0x0024, "Orphan reference: " + ref.target_id)
      END IF
      graph.ADD_EDGE(node.node_id, ref.target_id, ref.predicate)
    END FOR
  END FOR

  # Cycle detection with priority queue              // M-205
  queue ← PRIORITY_QUEUE(STABLE_ORDER_COMPARATOR)
  FOR node IN graph.nodes WHERE node.in_degree = 0 DO
    queue.PUSH(node)
  END FOR
  processed ← 0
  WHILE queue NOT EMPTY DO
    n ← queue.POP()
    processed ← processed + 1
    FOR neighbor IN graph.SUCCESSORS(n) DO
      neighbor.in_degree ← neighbor.in_degree - 1
      IF neighbor.in_degree = 0 THEN queue.PUSH(neighbor) END IF
    END FOR
  END WHILE
  IF processed ≠ graph.NODE_COUNT() THEN
    HALT(0x0025, "Ontology cycle detected")
  END IF

  FOR inv IN [INV001..INV009] DO                    // M-206
    result ← inv.CHECK(graph)
    IF result ≠ PASS THEN HALT(0x0026, inv.id) END IF
  END FOR

  # Sort all collections per Stable Ordering Contract // M-207
  graph ← SORT_GRAPH(graph,
             BY_ZE_ID_ASC, BY_UUID_ASC, BY_NAME_ASC)

  # Build ACV payload object
  acv_payload ← {
    artifact_type:         "active_constitutional_view",
    artifact_version:      "1.0",
    acv_version:           COMPUTE_ACV_VERSION(manifest, sr001),
    produced_at_logical:   "STAGE2_COMPLETE",
    sealed_at_unix_ms:     manifest.sealed_at_unix_ms,
    manifest_integrity:    manifest.integrity,
    sr001_integrity:       sr001.integrity,
    supersessions_applied: len(sr001.entries),
    deprecated_excluded:   COUNT_DEPRECATED(active_corpus),
    clusters:              EXTRACT_CLUSTERS(graph),
    predicates:            EXTRACT_PREDICATES(graph),
    patterns:              EXTRACT_PATTERNS(graph),
    invariants:            EXTRACT_INVARIANTS(graph),
    governance_rules:      EXTRACT_RULES(graph),
    taxonomy_rules:        EXTRACT_TAXONOMY(graph)
  }

  # Envelope pattern: hash payload only (not envelope)
  payload_canonical ← RFC8785_CANONICALIZE(acv_payload)
  acv_hash          ← SHA256(payload_canonical)

  WRITE_FILE("acv.json", {
    "payload":   acv_payload,
    "integrity": { "algorithm": "sha256", "value": acv_hash }
  })

  EMIT_STAGE_RECEIPT(2, "acv.json")                 // M-209

  RETURN ACVResult {
    path:             "acv.json",
    payload_hash:     acv_hash,
    node_count:       graph.NODE_COUNT(),
    edge_count:       graph.EDGE_COUNT(),
    sealed_at_unix_ms: manifest.sealed_at_unix_ms
  }

END FUNCTION
```

## 21. Prohibited Transitions

- `FAILED` → any state (no resurrection from FAILED)
- Any forward skip (e.g., CREATED → ACV_BUILT)
- Any backward transition (e.g., ACV_BUILT → SIA_PASSED)
- External injection of any transition

## 22. Resumption Rule

An interrupted compiler may resume from the interrupted stage if and only if:
- The input artifact for that stage exists on disk
- The input artifact integrity hash is verified before consumption
- Resumption begins from the interrupted stage's defined input; prior stages are not re-executed

Resumption is not a backward transition. It begins from the verified intermediate artifact.

## 24. Error Severity Rules

**SR-001 — Critical/Major Halt:** No implementation SHALL attempt to recover from CRITICAL or MAJOR errors. Pipeline MUST halt. Recovery is manual and requires correction of the constitutional input.

**SR-002 — Static Remediation:** The `recovery_action` field in every error record SHALL be populated from a static pre-authored mapping keyed on error code. Dynamic generation is prohibited.

**SR-003 — Minor Warning:** MINOR errors (currently only 0x00FB) allow the pipeline to continue. They MUST be logged and reported in the Artifact Manifest. They MUST trigger a governance review notification.

# Part VII — Deterministic Execution Rules

## 26. Determinism Budget

Every forbidden entropy source listed below results in 0x00F6 (DETERMINISM_VIOLATION) if used:

| Source | Status | Required Normalization |
|---|---|---|
| System clock | PROHIBITED | Use `sealed_at_unix_ms` from manifest |
| Timezone / locale | PROHIBITED | Compiler must run in invariant locale |
| Random number generator | PROHIBITED | BLAKE2b deterministic seeding only |
| Filesystem iteration order | PROHIBITED | Sort by canonical key before processing |
| Hash-map iteration order | PROHIBITED | Convert to sorted list before processing |
| Thread scheduling | PROHIBITED | Ordering operations are single-threaded |
| Floating-point formatting | PROHIBITED | No floats in constitutional data |
| Process ID | PROHIBITED | Never used in any computation |
| Network state | PROHIBITED | Compiler is fully offline |
| Environment variables | PROHIBITED | All inputs are declared artifacts |

## 27. Stable Ordering Contract

Whenever multiple valid orderings exist, implementations SHALL apply this comparator in priority order:

1. ZE-ID ascending (lexicographic)
2. UUID ascending (lexicographic)
3. Canonical Name ascending (lexicographic)

This comparator governs: Population Unit Assembler (M-307), Topological Sort priority queue (M-402), ACV Serializer (M-207), and all sorted collections in all artifact payloads.

## 28. Canonical Serialization Rule

All constitutional artifact hashes SHALL be computed from RFC 8785 JSON Canonicalization Scheme output:

- Keys sorted lexicographically
- All Unicode sequences normalized
- No whitespace except within string values
- UTF-8 encoding throughout

Native language JSON library output SHALL NEVER be hashed directly. The canonical bytes are the constitutional unit of truth.

## 29. Payload Envelope Rules

**AE-001:** Every constitutional artifact file on disk SHALL contain exactly two root keys: `payload` and `integrity`. No other root-level keys are permitted.

**AE-002:** The `integrity.value` SHALL be `SHA256(RFC8785_CANONICALIZE(payload_object))`.

**AE-003:** Self-describing headers (`artifact_type`, `artifact_version`, etc.) reside inside `payload`.

**AE-004:** The integrity hash covers only the payload. The envelope wrapper is delivery infrastructure and participates in no hash computation.

## 30. Logical Epoch Anchor Rules

**LA-001:** `sealed_at_unix_ms` is a constitutional constant for this version of the constitution. It is set during Phase A.1 closure and never modified.

**LA-002:** All UUIDv7 generation within RI-001 SHALL use `sealed_at_unix_ms` as the 48-bit timestamp block. System clock access for UUID generation constitutes 0x00F6.

**LA-003:** M-503 seed: `BLAKE2b(source_entity_id + ":" + relationship_type + ":" + target_entity_id + ":" + schema_version)`. Timestamp = `sealed_at_unix_ms`. Entropy block = truncated BLAKE2b output.

## 35. Hash Mismatch Resolution Protocol

When independent compilers produce differing hashes:

```
Step 1  FREEZE   Halt registry publication immediately
Step 2  DUMP     All three compilers output all intermediate artifacts
Step 3  ISOLATE  Diff intermediate artifacts stage-by-stage to find divergent stage
Step 4  CLASSIFY Classify divergence: Compiler Bug OR Specification Ambiguity
Step 5  COUNCIL  Architecture Council reviews root cause and classification
Step 6  LOG      Resolution documented in resolution_log appended to Artifact Manifest
Step 7  REPAIR   Fix compiler bug in affected implementation(s)
Step 8  RERUN    All three compilers rerun; Level 1 corpus re-validated
Step 9  FREEZE   New corpus hashes frozen only after unanimous PASS
```

No compiler may be considered conformant until all three produce identical hashes against the same constitutional input.
