# 1. Purpose

BAS-001 establishes the canonical assumptions used as the starting state for every Constitutional Economic Simulation.

Rather than embedding assumptions inside the simulator, BAS-001 separates assumptions from mathematics.

This allows the same simulation engine to evaluate multiple strategic futures while maintaining complete transparency and reproducibility.

---

# 2. Constitutional Philosophy

The simulator shall never invent assumptions.

Every forecast must begin from a defined constitutional baseline.

Changing assumptions changes projections.

Changing assumptions shall never change constitutional principles.

Every operating year,

actual platform performance shall be compared against BAS assumptions.

Differences become calibration inputs for future simulations.
