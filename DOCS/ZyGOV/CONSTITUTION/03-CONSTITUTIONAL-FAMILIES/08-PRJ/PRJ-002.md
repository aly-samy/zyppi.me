# PRJ-002 — GS1 Digital Link Projection Specification

###### Version: 1.0 Draft

**Parent Constitutions:**

- ZRM
- ARM-001
- ARM-P-001
- PRJ-001

**Status:**

Ratified 

---

# 1. Mission

`PRJ-002` defines how canonical Asset Reality is projected into GS1-compatible representations.

**`PRJ-002` SHALL NOT:**

- define products
- define batches
- define serialization
- define supply chains
- define observations
- define relationships

These concerns are constitutionally governed elsewhere.

`PRJ-002` governs only transformation.

---

# 2. Constitutional Principle

A GS1 representation is a projection.

It is not reality.

It is not storage.

It is not identity.

It is not authoritative.

The authoritative source remains Asset Reality.

**Projection function:**
````
Reality View
+
Policy Set
+
GS1 Projection Rules
=
GS1 Output
````
---

# 4. Identity Resolution

````

      ↓

      ↓
````

No GS1 identifier may bypass `zID` resolution.

# 7. Batch Asset Model

A Batch SHALL be treated as an Asset Reality.

**A Batch may:**

- own observations
- own expiry
- own quality records
- own recall events
- participate in custody chains
- participate in traceability

**Structure:**
````
Product Template
      ↓
Batch Asset
      ↓
Product Instance
````

---

# 8. Recall Projection

Recall status SHALL be computed.

Recall status SHALL NOT exist as stored state.

**Computation:**
````
Recall Observation
+
Remedy Observation
+
Reality View
=
Recall Projection
````
**Output values:**
````
active
resolved
unaffected
````
A Recall Projection SHALL include:

- status
- recall reference
- derivation timestamp
- policy reference

---

# 9. EPCIS Projection

EPCIS output SHALL be generated from Observation History.

**Inputs:**
````
CL-11 Events
Relationships
Identity Bindings
````
**Outputs:**
````
GS1 EPCIS XML
GS1 EPCIS JSON-LD
````
`PRJ-002` SHALL NOT store EPCIS records.

EPCIS output SHALL always be regenerable from Reality View.

# 12. Constitutional Independence

If GS1 standards disappear:

- ZRM survives.
- ARM-001 survives.
- ARM-P-001 survives.
- PRJ-001 survives.

Only PRJ-002 becomes obsolete.

This is the final constitutional test.

Any amendment that causes GS1 concepts to become required constitutional primitives SHALL be rejected.

- Reality remains independent.

- Identity remains independent.
- 
- Observations remain independent.
-
