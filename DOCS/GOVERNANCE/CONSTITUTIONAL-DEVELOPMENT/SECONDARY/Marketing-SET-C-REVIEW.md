# 3. Material Review Findings

## 3.1 Marketing-013 Truncation Claim — REJECTED

The canonical `Marketing-013 v1.0` file was complete. The truncation observed by the independent reviewer came from an incomplete/stale representation, not the canonical artifact.

## 3.2 B2B Out-of-Market / Mental Availability Gap — ACCEPTED

`Marketing-012 v1.1` now recognizes:

- in-market vs out-of-market demand;
- Demand Capture vs Demand Creation;
- Category Entry Points;
- Mental Availability;
- Mental Penetration;
- Network Size;
- Mental Market Share.

The commonly cited 95:5 formulation is treated only as an external planning heuristic.

**No fixed 95/5 ratio is constitutionalized.**

Mental Availability remains a leading market-memory condition and does not substitute for E3/E4 product validation.

## 3.3 Enterprise Experiment Credibility Risk — ACCEPTED

`Marketing-011 v1.1` now establishes Institutional Experiment Safety.

High-consequence enterprise, infrastructure, Trust, compliance, and institutional buyers should not be subjected to materially deceptive fake availability or commercially incoherent testing that can damage buyer trust.

## 3.4 Physical / Institutional Lead-Time Blindness — ACCEPTED WITH CORRECTION

The durable problem is accepted; no universal packaging-cycle duration is adopted.

Set C now recognizes:

- External Incubation;
- dependency-bound activation;
- Zyppi-Controlled TTFV;
- External Incubation Time;
- Total Elapsed Time to Activation.

A participant waiting on a documented external dependency is neither activated nor automatically churned.

## 3.5 Receipt / Registry Bureaucracy Risk — ACCEPTED

Set C now strengthens Minimum Viable Governance:

- low-consequence experiments do not require Council sign-off by default;
- receipts preserve institutional memory rather than create permission queues;
- claim governance scales with consequence;
- low-consequence copy can iterate without Council pre-approval by default;
- P0/P1 domain exploration remains lightweight.

No universal five-minute receipt rule is constitutionalized.

## 3.6 Commerce Activation Definition — CORRECTLY DEFERRED

The exact Commerce activation event must be defined before meaningful scale reporting, but it belongs in:

- `Marketing-PLAN-1Y-001`;
- the Commerce/GS1 program;
- the Metric Dictionary.

It should not be constitutionalized in Set C.

## 3.7 Domain Vocabulary Inflation — ACCEPTED

`Marketing-014 v1.1` makes Domain a governed strategic classification.

An initiative cannot bypass expansion gates merely by calling itself a domain.

## 3.8 1-Year Plan Theater — ACCEPTED

`Marketing-015 v1.1` now defines the 1-year plan as a living strategic control surface rather than a certainty contract.
